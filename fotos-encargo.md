# Fotos que le faltan a Naira

Naira es una guía de Tenerife. Cada parada enseña una foto; cuando no la hay,
pone una ortofoto aérea. Para una playa se defiende, pero para un museo o una
iglesia es un tejado visto desde arriba y no dice nada. Estos 33 sitios son
los que MÁS salen en los planes y peor se ven. Van ordenados por eso.

## Las reglas, que aquí es lo que importa

1. **Tiene que ser una foto real de ese sitio exacto.** Ni generada, ni de otro
   sitio parecido, ni de otro pueblo. Una foto inventada de un sitio que existe
   es lo peor que le puede pasar a esta guía: el turista va y no lo reconoce.
2. **Con autor y licencia, o no vale.** Wikimedia Commons sirve. Sin crédito no
   se puede publicar, así que una foto sin autor conocido se descarta entera.
3. **Si no la encuentras, dilo y pasa a la siguiente.** No hay que rellenar la
   lista. Aquí la regla de la casa es que antes callarse que inventar.
4. Que se vea el sitio, no un cartel ni un folleto ni un plano.

## Qué hay que entregar

Un zip con:

- una imagen por sitio, **llamada exactamente como la columna «fichero»**
  (`Casa del Plátano.jpg`). Cuadrada o casi; se recorta y se achica luego.
- un `creditos.json` así, con el nombre del sitio tal cual:

```json
{
  "Casa del Plátano": {
    "autor": "Nombre del autor",
    "licencia": "CC BY-SA 4.0",
    "fuente": "https://commons.wikimedia.org/wiki/File:..."
  }
}
```

Las coordenadas están para **comprobar que la foto es de ese sitio**, no para
buscar por ellas: hay museos con el mismo nombre en dos pueblos.
